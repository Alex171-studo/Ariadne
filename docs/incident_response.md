# Procédure de réponse aux incidents

## Niveau critique

Un incident est considéré critique lorsqu'il entraîne :

- Une fuite de données
- Un ransomware
- Une indisponibilité supérieure à 30 minutes

## Étapes

1. Identifier l'incident
2. Isoler les systèmes concernés
3. Prévenir le SOC
4. Collecter les preuves
5. Restaurer les services
6. Produire un rapport

## Délai de notification

Toute fuite de données doit être signalée dans les 24 heures.

## Responsable

Le SOC Manager dirige la cellule de crise.
