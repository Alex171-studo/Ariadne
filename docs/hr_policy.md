# Politique RH

## Télétravail

Les employés peuvent télétravailler jusqu'à trois jours par semaine avec l'accord de leur manager.

## Congés

Les salariés disposent de :
- 25 jours de congés payés
- 10 jours de congés maladie

## Horaires

Heures normales :
08h00 - 17h00

Pause déjeuner :
12h30 - 13h30

## Formation

Chaque employé bénéficie d'un budget annuel de 1200 € pour les formations.

Les certifications en cybersécurité sont encouragées :
- Security+
- CEH
- CISSP
- AZ-500
